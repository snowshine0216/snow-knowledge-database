# I asked Claude Code to make me as much money as possible

AI automation creator Nate Herk lays out four workflow changes to Claude Code that he says 3x'd his income in 30 days, each targeting a specific failure mode he argues most users never notice. He demonstrates all four live by building a fictional $9/month SaaS idea end-to-end — from adversarial validation through a landing page build to a six-file go-to-market kit generated by parallel subagents.

## Key Concepts
- **[[roast-skill]] (anti-sycophancy council)**: A custom `/roast` skill spins up five persona subagents — contrarian (finds fatal flaws), expansionist (biggest upside), first-principles thinker (no outside context), deep researcher (pulls real market/competitor data), and buyer (role-plays the customer) — plus a judge that synthesizes a single green-light/reshape/kill verdict with a confidence score and the cheapest 48-hour validation test. Built to counter the [[elephant-sycophancy-study|ELEPHANT study]] finding that AI models fail to push back on how a user frames something ~88% of the time (vs. ~60% for humans), a problem that *worsens* with more personalization/memory per MIT/Penn State research.
- **Build-then-verify methodology**: Before Claude hands over any output, it verifies its own work (e.g., Playwright screenshots at desktop/mobile viewports against an explicit "definition of done"), then separately stress-tests it with adversarial inputs (malformed emails, edge-case form data) to surface bugs neither the user nor Claude anticipated. Motivated by an NYU study finding ~40% of ~1,600 GitHub Copilot-generated programs had security vulnerabilities, and Nate's own anecdote of an outreach-email agent that silently sent only 25% of "hundreds" of emails while confidently reporting full success.
- **[[context-rot]] management**: Research across 18 models shows conversation quality degrades well before the context window fills up ("context rot"). Nate uses `/context` to visualize token consumption, and a custom `/session-handoff` skill — writing a structured resumable summary (decisions locked, key files, open items, where to pick up) before running `/clear` — instead of relying on `/compact`. Personal reset threshold: ~25% of a 1M-token context window.
- **Parallel [[subagents]] + `/goal`**: Cites Anthropic's own internal finding that a lead-agent-plus-subagent-team setup beat a single agent by over 90% on their research evaluation. `/goal` sets an explicit, objective completion condition and lets Claude work turn-by-turn until met — critically, a *separate evaluator model* grades "done," so Claude cannot self-declare completion, structurally reinforcing the anti-sycophancy fix from upgrade 1.

## Key Takeaways
- Treat Claude's agreement as a default risk, not a signal of quality — build in adversarial review (a persona council, or simply "play devil's advocate") before committing to any idea or plan.
- "Finished" and "working" are separate claims; require self-verification (screenshots, test runs against a stated definition of done) before trusting an AI-reported "done."
- Actively curate context instead of letting `/compact` handle it — a structured handoff-then-clear pattern preserves continuity without the silent quality drop-off of long conversations.
- Parallel subagents plus an externally-graded `/goal` condition shift the human from builder/producer to reviewer/decision-maker, removing the single-threaded bottleneck of one linear conversation.
