# AI Token Resource War

这篇 AI前线整理的 Dylan Patel 访谈把 AI 竞争重新定义为资源战争：模型能力仍然重要，但真正决定胜负的是谁能拿到更聪明的 token、谁能为 token 付费、谁能把 token 指向可捕获经济价值的任务。SemiAnalysis 的例子很直接：AI token 年化支出从几万美元级别升至 700 万美元，对比 2500 万美元薪资成本，已经超过薪资的 25%。这些 token 没有只用于聊天或总结，而是变成执行资本：一名员工用几千美元 token 做出芯片图片材料识别和有限元分析系统；前银行经济学家 Malcolm 用 FRED、就业报告和 BLS 2000 项任务建立宏观分析与 AI 可替代性评估；Jeremy 每天约 6000 美元 token、3 周内抓取美国发电厂和高压输电线路数据，做出能源供需可视化。

## Key Concepts
- **Token as execution capital**: token 不再是 SaaS 订阅费，而是购买执行力的资本预算。SemiAnalysis 的 700 万美元开销对应芯片逆向、经济模型、能源数据产品等新资产，而不是单纯办公效率。
- **Frontier access as competitive advantage**: Dylan 认为前沿模型的关键不是便宜，而是访问权。Anthropic 企业合同、客户经理、rate limit 和 Mythos/Opus 4.7 这类前沿模型访问，都会变成企业差异化资源。
- **Smarter token economics**: Mythos 的单 token 价格据称可达当前成本 5-10 倍，但如果“单位 token 更聪明”、完成任务所需 token 更少，任务总成本可能下降。价值来自能力上限提升，而不是旧能力降价。
- **Execution-to-judgment shift**: 执行变容易后，稀缺点转向判断力：选对问题、把 AI 输出转化成产品或收入、获取资本和算力放大成果。低阶用法是把 8 小时工作压缩到 1 小时；高阶用法是继续工作 8 小时，把产出放大到 8 倍。
- **Infrastructure bottleneck stack**: 需求会反向重估整条实体供应链。内存产能每年只能增长约 20%-30%，新增产能可能到 2027 年末或 2028 年才落地；台积电资本开支已达 500 多亿美元量级；ASML、Lam Research、Applied Materials、铜箔、玻纤、激光器等上游环节都会承压。
- **CPU as hidden AI bottleneck**: GPU/ASIC 负责模型“思考”，CPU 负责强化学习环境、CAD 仿真、代码运行和应用执行。AI 生成越多内容，执行层 CPU 需求越容易被低估。
- **Phantom GDP**: AI 可能让真实产出增加，同时成本下降更快，导致统计 GDP 低估价值。更便宜、更强的信息服务会改善客户投资和竞争决策，但这部分收益不一定完整进入 GDP。

## Key Takeaways
- AI 成本下降不会降低前沿需求，反而会把需求推向更强模型。旧 GPT-4 级能力未来即使便宜 100 倍，企业仍会追逐能创造新经济价值的下一代模型。
- 企业的 AI 战略不能只做成本控制。更关键的是把 token 预算绑定到可复用资产和收入线，如数据集、分析系统、自动化产品、客户可见服务。
- 算力短缺会让模型公司保持高毛利，也会让硬件供应链上游获得定价权。[[nvidia-new-moat-strategy]] 里的“硬件到平台”逻辑和这里的供应链重估是同一条主线。
- 个人和小团队的窗口在于价值捕获，而不是只提升效率。只用 AI 偷懒会很快变成标配；用 AI 扩大产出并占有收入，才可能形成结构性优势。
- AI 行业的公众沟通需要从“未来会颠覆一切”转为“当下具体改善什么”。Dylan 预测反 AI 情绪可能快速上升，原因是就业焦虑、神秘化叙事和少数公司资源集中叠加。
