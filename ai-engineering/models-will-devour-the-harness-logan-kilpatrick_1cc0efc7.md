## Executive Summary
红杉合伙人 Sonya Huang 对话 Google AI Studio 负责人 Logan Kilpatrick。核心论点只有一句：**“每一行外部脚手架，都是对模型无能的妥协，这种红利顶多还有 12 个月。”** Logan 判断模型很快会把 Harness（Agent 运行框架/中间件）原生吞进自身，市面上约 90% 的 Agent 中间件公司活不过 12 个月；创业公司唯一活路是去打有专业知识壁垒的垂直深水区，而不是在通用工具上和大厂死磕。他同时给出几条反主流观察：AI 时代商业逻辑从“最大化眼球停留”转向“最大化用户结果”；Gemini 3.5 Flash 仅靠后训练（post-training）就在编程上超过了之前所有 Pro 模型；世界模型与视频模型的边界正在被 Omni 这类单一模型抹平。

## Outline
1. **Anti-Gravity 成为新主线** — Agent 运行框架取代 Gemini API，成为串起 Google 所有产品的新底座。
2. **最大化结果，不是最大化眼球** — Agent 时代用户停留时长下降，胜负取决于谁用最少点击交付结果。
3. **只有代码 Agent 真的跑起来了吗** — 长时程 Agent 是关键 KPI，编程是已被验证的通用 Agent 用例。
4. **Gemini 为何在编程上声量低** — 叙事风向变化快、Anti-Gravity 与 Windsurf 收购、3.5 Flash 全靠后训练。
5. **代码已是狭义超级智能** — 编程能力强到接近 narrow ASI，且抬高了开发者的野心阈值。
6. **世界模型边界变模糊** — Omni 单一模型同时具备世界理解与生成能力，吞掉传统 world model 用例。
7. **不是 AI 替身，而是放大原内容** — 生成式媒体应改变布景而非改变“人本身”。
8. **模型会把脚手架吞进去** — “模型”早已不只是权重，Harness 终将被原生消化，价值点转移。
9. **创业公司还有什么生存空间** — 能力冗余 + 垂直专注是创业公司对抗大厂的超能力。
10. **GDM 文化** — “复仇者联盟”代码团队、引擎室定位、非零和的“把世界变得更好”。

## Detailed Chapter Summaries

### 1. Anti-Gravity 成为新主线
Logan 把 Google 当前阶段定义为“Gemini 3.5 时代”，真正的 agentic 时代才刚落地。历史上 Google 有约 50 个产品但缺一条贯穿主线，Gemini 出现后成为这条主线（所有东西都在用 Gemini）。现在这一角色正交给 **Anti-Gravity**——一个 agent 运行框架，包含核心 IDE、agent-first 网页体验、CLI 和 SDK，并将驱动搜索、Gemini App、云端、AI Studio 的 agent 能力。

> “它本质上真的是一整套生态系统……目的是在开发者所处的任何场景中都能接住他们。”

- 关键区分：以前是“语言模型 API”作为嵌入式主线，现在升级为“agent 运行框架”作为主线。
- 编程被定位为这个通用 agent 运行框架的一个“专门化用例”——基础框架约 80% 内容相同，再按编程/消费级等场景做 20% 定制（如 AI Studio 针对 vibe coding 定制，Gemini App 针对全天候消费级 agent 定制）。

### 2. 最大化结果，不是最大化眼球
面对“agent 会蚕食产品停留时长”的担忧，Logan 用搜索做反例：AI 直接答题原以为对搜索是负和，结果反而极其正和——人和 agent 都搜得更多，催生了一个新市场。

> “Google 的成功，大概不会表现为‘尽可能让用户多盯着我们的产品看’；而会表现为‘尽可能帮助用户实现结果’。”

#### 智能体增长与 GEO
- Sonya 提出“智能体增长”：她让编程 agent 替自己做所有基础设施选择（“我不在乎用什么数据库，你来定”）。Logan 认为购物等领域也会出现类似现象。
- SEO 正在演化为 GEO（生成式引擎优化），二者高度相关，转变更可能是层层复合而非剧烈断裂。

#### 爬/走/跑评分
- Google 整体仍处“爬”阶段——因为坐拥十几款、合计百亿级用户的产品，长尾用户还没准备好让 AI 全自动接管，搜索团队尤其有“把用户一起带上”的责任。
- 最接近“走/跑”的是 Gemini App（如 Spark 这种 7×24 在线 agent）和 Anti-Gravity（自主编程 agent 可“替你花几千美元、跑数十亿 token 重建操作系统”）。
- 产品数量之争（一两个统一入口 vs 成千上万个）会是战略选择；Logan 个人倾向人类喜欢“分隔感/专门化”，不看好“一个什么都能干的产品”，并以幻灯片长寿为例——人脑习惯信息固定在同一位置，生成式界面可能反而增加认知负担。

### 3. 只有代码 Agent 真的跑起来了吗
企业普遍反馈“唯一真正见效的 agent 就是编程 agent”。Logan 认为这取决于“有效”的门槛，并提出一个他很想测的指标：**平均单次 agent 运行的持续时长**——新模型上线后长时程任务会突然抬头，各实验室都在宣称“能自主工作三天”。
- 长时程 agent 与编程 agent 都是 DeepMind 的高优先级 KPI；强编程模型是业务其他部分的加速器。
- 预测：即使编程之外的企业用例今天还没强烈见效，今年内也会变好。

### 4. Gemini 为何在编程上声量低
Sonya 直言朋友圈“一半用 Claude、一半用 Codex，几乎没人提 Gemini”。Logan 补背景：去年 12 月 Gemini 3 发布时外界叙事是“Google 赢了”，但下一阵风很快吹到 agentic coding（OpenAI 进入“红色警报”、Codex 变强）。

> “一个重要教训是：如果你自己没有一个真在做这件事的产品，那你很难为开发者做出优秀的编程模型。”

- 这正是收购 Windsurf 团队、打造 Anti-Gravity 的原因——必须让飞轮（dogfooding → 反馈 → 模型变好）转起来；Sundar 在 I/O 展示过 Google 内部 token 消耗增长曲线。
- 负责代码方向的团队被 Logan 称为内部“人工智能复仇者联盟”。
- **3.5 Flash 的关键事实：它是 Flash 模型，但编程能力超过之前所有 Pro 模型，且提升“全部来自后训练（post-training）”**——外界常忽略“预训练大跑次/算力集群何时启动”这一隐藏上下文，DeepMind 在预训练上历来很强。
- 内部仍鼓励用所有模型（更健康、看清生态），但 Gemini 是十万+工程师的日常主力，构成反馈飞轮的竞争优势。

### 5. 代码已是狭义超级智能
Logan 重申旧观点：能用代码构建任何东西、人类无法在同层竞争的系统，就是一种 narrow superintelligence，而编程现在“确实已经有那种感觉”。
- 他强调不要让“打造 AGI”的宏大叙事掩盖“仅仅擅长代码就已极具影响力”这一现实。
- 对开发者的影响是“加速器”而非取代：他个人感到“行动能力变多、可以做更有野心的问题”，甚至产生新负担——“不能只做 MVP 了，得再往前走十步”。
- 预测形态：在“解决”通用智能前，会先得到很多**参差/锯齿状（jagged）的垂直领域超级智能**；下一批可能起飞的是可验证性强的领域——数学、金融、科学。

### 6. 世界模型边界变模糊
Logan 认为“世界模型”的定义本身会变模糊，编程 agent 最终看起来也像某种 world-model 式系统。
- **Omni**（I/O 发布）是单一模型：任意输入→任意输出，把过去需要训练 8 个模型（文本 Gemini、音频、Lyria 音乐、Nano Banana、Veo 视频…）的能力收进一个架构；不是路由到一堆模型，而是真正的 Omni 模型。
- 当前先开放效果最好的视频编辑用例；这只是 Omni Flash 第一版。
- 与传统 world model（如 Genie，可理解为“动作条件视频模型”）相比，Omni 的优势是扩展性——传统在线世界模型运行成本极高。
- 现场轶事：演讲中让观众用 Omni 实时编辑现场画面，画面里“一只狗走上舞台、其他嘉宾低头轻笑、狗跳到他腿上、他顺手摸狗继续讲话”，无数微妙反应都做对，体现出真正的世界理解。

### 7. 不是 AI 替身，而是放大原内容
针对生成式媒体，Logan 给出一条产品原则：他坚持不用 AI 生成“自己产出的内容”（文字、声音、形象都要真实是本人）。

> “它不是在改变‘我’。它改变的是其他那些部分，而那些并不是‘我’。”

- Omni 的价值在于改变布景、咖啡桌等“不那么属于人”的部分，让原始内容被放大、增强，而不是做一堆“AI 虚拟化身/水果岛视频”。

### 8. 模型会把脚手架吞进去（全篇核心）
Logan 论证“模型吞噬 Harness”为真，关键在于**“模型”早已不再只是一组权重**。
- 两年前 LLM“模型”≈ 一组权重 + 把 token 送进送出；如今 Gemini 3.5 / GPT / Claude 是“围绕权重不断扩展的完整系统”：agentic 工具调用、托管工具、搜索、代码执行，模型会在容器里启动、自带 agent 运行框架。

> “脚手架往往总是比真正内建到模型里的东西领先一两步。然后模型把这层脚手架吞进去，它变成原生模型系统的一部分。”

- 12 个月判断：今天“真正的价值在运行框架里”的说法，再过 12 个月将不再以现在的方式成立——模型会原生消化大部分，价值点转移到别处。
- 对“自建 Harness 防锁定”的反驳：随着模型变强，这条理由越来越站不住；“一个连别人运行框架都用不了的模型，不能算真正通用的模型”。他提议业界做一个 **“运行框架基准（harness benchmark）”**，衡量不同模型适配各种框架的能力。
- 留有余地：搜索、代码执行等场景外部脚手架仍有价值（不同搜索提供商/需求）。

### 9. 创业公司还有什么生存空间
Logan 认为两个看似矛盾的命题同时成立：从未有这么多机会去构建新东西，同时模型又比任何时候做得更多。
- 两条机会线索：**能力冗余**；以及大厂只追通用大问题，**垂直深水区 + 领域专业知识**能把顶尖实验室甩开。

> “专注就是创业公司的超能力。只要你能专注，你几乎什么都能做成。”

- 大公司（含 Google 自己）有义务做很多事，难以专注；创业公司没有这个包袱。
- 编程能力拉近了创业公司与“坐拥庞大代码库的大厂”的差距（你能跑得更快）；“agent”本身是一个全新可构建品类；不同公司风险偏好不同，愿担风险者能赢得愿担风险的用户。

### 10. GDM 文化
Logan 给出三点观察：
1. **投资组合视角**：同时做很多押注，组合很强，但偶尔会被别的实验室在某个方向超过（投入/聚焦不够）；看团队如何缩小差距很酷。引用纪录片《The Thinking Game》——文化仍是“把聪明人聚在一起解决问题”。
2. **文化自上而下渗透**：Demis 是诺奖科学家 → DeepMind 偏科学方法论、为治愈疾病等重大问题而做；Sam → OpenAI 偏商业气质；Dario / Anthropic 偏“玄学气质”。
3. **Google 的“引擎室”**：一边深厚实验室文化，一边要把 Gemini 部署进 13 个十亿用户级产品——这种问题全球可能只有两家公司遇到。

> 最爱名言（Gavin Belson 梗）：“我们不能让别人把世界变得比我们更好。”——Logan 借此说明这件事根本不是零和。

## Playbook

### 别把 Harness 当壁垒
- **Key idea**：外部脚手架/中间件是“对模型无能的妥协”，红利窗口约 12 个月，约 90% Agent 中间件公司会被模型原生能力吞掉。
- **Why it matters**：把工程重心押在通用 Harness 上，会随模型每次迭代而贬值。
- **How to apply**：把“运行框架”当临时手段而非护城河；用 harness benchmark 心态选模型——优先能适配多种框架、能力外溢的底座，而不是绑死自建中间件。

### 创业要打垂直深水区
- **Key idea**：通用工具上和大厂死磕必输；唯一活路是有领域知识壁垒的垂直场景。
- **Why it matters**：大厂被“必须做很多事”的义务拖累，无法专注；专注是创业公司的超能力。
- **How to apply**：选一个你比顶尖实验室更懂客户/生态/行业运转的窄领域，用编程能力把迭代速度拉满，围绕“agent”这一新品类构建。

### 从最大化眼球转向最大化结果
- **Key idea**：Agent 时代用户停留时长必然下降，赢家是用最短时间/最少点击交付结果的人。
- **Why it matters**：靠在线时长换广告的旧互联网逻辑在 agent 时代失效。
- **How to apply**：用“帮用户完成事情后离开”而非“留住用户”来定义产品成功与指标。

### 后训练是被低估的爆发力
- **Key idea**：Gemini 3.5 Flash 仅靠 post-training 就在编程上超过此前所有 Pro 模型。
- **Why it matters**：性能跃升不只靠烧钱预训练；剪枝/对齐阶段能释放超预期能力，外界常因看不到“大跑次启动时点”而误判某家落后。
- **How to apply**：评估某实验室进度时，把“预训练窗口/算力集群何时启动”当作隐藏上下文，别只看当下榜单声量。

### 生成式媒体：放大“人”，而非替换“人”
- **Key idea**：用 Omni 改变布景等“非人”部分，保留本人的文字、声音、形象。
- **Why it matters**：真实感本身是价值；满屏 AI 虚拟化身会稀释内容可信度。
- **How to apply**：内容生产中，把 AI 用在背景/形式增强上，核心表达仍由真人产出。
